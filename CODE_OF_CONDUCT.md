# Code of conduct

## The short version

Be decent. Argue with the work, never with the person.

## What is expected

- Assume the other person read the docs and still got stuck. Usually they did.
- Criticise a claim by showing the evidence against it. This project is built on
  the idea that assertions carry proofs; the same applies in a thread.
- Accept a correction the way you would want yours accepted.

## What is not tolerated

Harassment, personal attacks, demeaning comments, unwelcome attention, or
publishing someone's private information. Also: pressuring anyone to help you
automate an application you are not allowed to automate.

## Enforcement

Report to the maintainer through a
[security advisory](https://github.com/jaf333/ghostapi/security/advisories/new)
if it involves private details, or a direct message otherwise. Reports stay
confidential. The maintainer may edit, hide or delete contributions, and may ban
an account, without owing a debate about it.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
kept short on purpose.
